# Aerial Image Classification of Residential Roofs for Resilient Retrofits
**AIM 350 - Term Group Project**

## Project Overview
This project uses a Genetic-Algorithm-Optimized CNN to classify residential roof conditions (healthy, requires maintenance, retrofit candidate) using custom aerial imagery.

## Data Access Instructions
Due to file size constraints, the raw DJI Mini 3 Pro drone dataset is hosted externally.
* **Download Link:** (https://drive.google.com/drive/folders/1JQqMYA3scLg8J_tO7jD-JGOo6GbKuw-a?usp=sharing)
* **Instructions:** Download the dataset and extract the image files directly into the local `/data` directory before running any scripts.

## Setup and Run Instructions
1. Clone this repository.
2. Install the required dependencies: `pip install -r requirements.txt`
3. Navigate to the `source/notebook/` directory to execute the PyTorch and GA pipelines.
